Here's the organized breakdown of your Composition & Render Management shortcuts:

## 🎬 After Effects — Composition & Render Management Cheat Sheet

### Composition Setup
| Shortcut | Action |
|----------|--------|
| **Ctrl / Cmd + N** | Create a new composition |
| **Ctrl / Cmd + K** | Open composition settings |
| **Ctrl / Cmd + Alt / Opt + P** | Open the last closed composition |

### Render & Export
| Shortcut | Action |
|----------|--------|
| **Ctrl / Cmd + M** | Add current comp to the Render Queue |
| **Ctrl / Cmd + Alt / Opt + M** | Add current comp to Adobe Media Encoder queue |

### Import
| Shortcut | Action |
|----------|--------|
| **Ctrl / Cmd + I** | Import single or multiple files |

---

**Quick tips:**
- **Ctrl/Cmd + M** sends to the classic **Render Queue** (inside AE); **Ctrl/Cmd + Alt/Opt + M** hands off to **Media Encoder** — great for H.264/HEVC and batch encoding.
- **Ctrl/Cmd + Alt/Opt + P** is a lifesaver when you accidentally close a comp tab — it reopens the most recently closed one.
- **Ctrl/Cmd + K** opens settings for the *active* comp — handy for quick resizes or duration tweaks without digging through menus.
