## 🎞️ After Effects — Layer Properties & Keyframes Cheat Sheet

### Single-Letter Property Reveals
| Shortcut | Property |
|----------|----------|
| **A** | Anchor Point |
| **P** | Position |
| **S** | Scale |
| **R** | Rotation |
| **T** | Opacity |
| **L** | Audio Waveform / Levels |

### Multiple Properties
| Shortcut | Action |
|----------|--------|
| **Shift + [Letter]** *(e.g., Shift + P + S)* | Reveal multiple properties simultaneously |

### Keyframe Visibility & Navigation
| Shortcut | Action |
|----------|--------|
| **U** | Reveal all animated/modified keyframes on a layer |
| **UU** *(press U twice)* | Reveal all modified properties |
| **J / K** | Jump to previous / next keyframe |

### Easing
| Shortcut | Action |
|----------|--------|
| **F9** | Easy Ease selected keyframes |
| **Shift + F9** | Easy Ease In |
| **Ctrl / Cmd + Shift + F9** | Easy Ease Out |

---

**Quick tips:**
- **Shift + letter** adds properties to the reveal rather than replacing it — so **Shift + P + S + R** shows Position, Scale, and Rotation together in one go.
- **U** is your "show me what's animated" key; tap **UU** to see *every* modified property (even non-keyframed tweaks like expressions or changed values).
- **F9** is the all-purpose ease; use **Shift + F9 / Ctrl+Shift + F9** when you need an asymmetric ease (only one side).
- **J / K** jumps keyframe-to-keyframe on *selected* properties — select the property rows in the Timeline first for precise navigation.
