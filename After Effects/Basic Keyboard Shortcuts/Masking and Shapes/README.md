## 🎭 After Effects — Masking & Shapes Cheat Sheet

### Creating Masks
| Shortcut | Action |
|----------|--------|
| **Ctrl / Cmd + Shift + N** | Create a new mask on the selected layer |

### Revealing Mask Properties
| Shortcut | Property |
|----------|----------|
| **M** | Mask Paths |
| **F** | Mask Feathering |
| **TT** *(press T twice)* | Mask Opacity |

### Layer Controls Visibility
| Shortcut | Action |
|----------|--------|
| **Ctrl / Cmd + Shift + H** | Show / hide all layer controls (masks, motion paths, bounding boxes) |

### Expressions
| Shortcut | Action |
|----------|--------|
| **Alt / Opt + Click** *(on stopwatch)* | Add or delete an expression on a property |

---

**Quick tips:**
- **Ctrl/Cmd + Shift + N** adds a mask to the *selected layer* — unlike **Ctrl/Cmd + N**, which makes a new comp. Watch that Shift!
- **M** reveals all mask paths on the selected layer; tap **MM** to reveal *all* mask properties at once (path, feather, opacity, expansion).
- **F** jumps straight to feathering — handy when you're refining soft edges. **TT** (double-tap T) reveals mask opacity, distinguishing it from the layer **T** for opacity.
- **Ctrl/Cmd + Shift + H** is the "declutter" toggle — hides mask outlines, motion paths, and bounding boxes so you can see the actual image. Great before previewing or screenshotting.
- **Alt/Opt + Click** on *any* stopwatch (not just masks) adds an expression; doing it again removes it. A quick way to pop open the expression field without the menu.
