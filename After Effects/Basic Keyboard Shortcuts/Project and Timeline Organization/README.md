## 📁 After Effects — Project & Timeline Organization Cheat Sheet

### Creating Layers
| Shortcut | Action |
|----------|--------|
| **Ctrl / Cmd + Alt / Opt + Y** | New adjustment layer |
| **Ctrl / Cmd + Shift + Y** | New solid layer |
| **Ctrl / Cmd + Alt / Opt + Shift + Y** | New null object layer |
| **Ctrl / Cmd + Alt / Opt + Shift + T** | New text layer |

### Layer Selection & Renaming
| Shortcut | Action |
|----------|--------|
| **Ctrl / Cmd + ↑ / ↓** | Select previous / next layer in the timeline |
| **Enter** *(main keyboard)* | Rename selected layer, composition, or effect |

### Render Freezing
| Shortcut | Action |
|----------|--------|
| **Caps Lock** | Freeze / unfreeze frame rendering (prevents preview refresh during structural changes) |

---

**Quick tips:**
- The **solid layer** combo (**Ctrl/Cmd + Shift + Y**) skips the Shift-free "Y" cluster — remember solids get a dialog, whereas nulls and text drop in instantly.
- **Ctrl/Cmd + Alt/Opt + Y** (adjustment layer) is a staple for applying effects over everything below it — no source layer needed.
- **Ctrl/Cmd + ↑/↓** cycles layer selection without clicking — fast for stepping through a stack when you're tweaking properties.
- **Enter** renames in place. On some laptops you may need **Fn + Enter** if the main Enter is missing — worth testing once.
- **Caps Lock** is a subtle lifesaver: with it on, the Comp panel stops re-rendering, so you can drag/reorder/split layers without the viewer flickering. Just don't forget to turn it off before previewing.
