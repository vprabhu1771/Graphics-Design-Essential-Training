## 🛠️ After Effects Tools Cheat Sheet

### Selection & Navigation
| Shortcut | Tool |
|----------|------|
| **V** | Selection Tool |
| **H** *(or hold **Spacebar**)* | Hand Tool (Pan) |
| **Z** | Zoom In Tool |

### Transform & Positioning
| Shortcut | Tool |
|----------|------|
| **W** | Rotation Tool |
| **Y** | Pan Behind (Anchor Point) Tool |

### Drawing & Masking
| Shortcut | Tool |
|----------|------|
| **Q** *(press repeatedly to cycle)* | Shape / Mask Tools |
| **G** | Pen Tool |
| **Alt / Opt + W** | Roto Brush Tool |

### Text
| Shortcut | Tool |
|----------|------|
| **Ctrl / Cmd + T** | Horizontal / Vertical Type Tool |

---

**Quick tips:**
- **Hold Spacebar** anywhere to temporarily switch to the Hand Tool — release to return to your previous tool.
- **Q** cycles through Rectangle, Rounded Rectangle, Ellipse, Polygon, and Star tools (or their mask equivalents depending on context).
- **Alt/Opt + W** is a handy one to memorize for rotoscoping work.
