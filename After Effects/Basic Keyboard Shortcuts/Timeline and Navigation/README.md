Here's the organized breakdown of your Timeline & Navigation shortcuts:

## 🎞️ After Effects — Timeline & Navigation Cheat Sheet

### Frame-by-Frame Navigation
| Shortcut | Action |
|----------|--------|
| **Page Down / Page Up** | Move forward / backward 1 frame |
| **Shift + Page Down / Page Up** *(or Shift + ←/→)* | Move forward / backward 10 frames |

### In / Out Points & Work Area
| Shortcut | Action |
|----------|--------|
| **I / O** | Go to layer In point / Out point |
| **B / N** | Set the start (B) / end (N) of the work area |
| **[ / ]** | Move the start / end of a selected layer to the playhead |

### Layer Editing
| Shortcut | Action |
|----------|--------|
| **Ctrl / Cmd + Shift + D** | Split layer at the playhead |
| **Ctrl / Cmd + Shift + C** | Pre-compose selected layers |
| **Ctrl / Cmd + D** | Duplicate layer or item |

---

**Quick tips:**
- **Page Up/Down** nudges the playhead a single frame — the finest-grained scrub. Add **Shift** for 10-frame jumps (great for rough timing passes). The arrow keys also work with Shift.
- **I / O** jumps to the *selected layer's* In/Out point — so select the layer first, then hit **I** or **O**.
- **B / N** define the **work area** (the shaded bar), which controls what gets RAM-previewed and what **Ctrl/Cmd + M** renders by default — not the comp duration itself.
- **[ / ]** snap the selected layer's In or Out point to the playhead — the classic ripple-trim move without dragging.
- **Ctrl/Cmd + Shift + D** splits; **Ctrl/Cmd + Shift + C** pre-composes (opens a dialog to name the new comp); **Ctrl/Cmd + D** duplicates.
