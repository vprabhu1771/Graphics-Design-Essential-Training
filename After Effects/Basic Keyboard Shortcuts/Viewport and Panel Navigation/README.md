## 🧭 After Effects — Viewport & Panel Navigation Cheat Sheet

### Composition Markers
| Shortcut | Action |
|----------|--------|
| **Shift + 1 / 2 / 3…** | Go to specific composition markers |

### Rulers, Guides & Grid
| Shortcut | Action |
|----------|--------|
| **Ctrl / Cmd + R** | Show / hide rulers |
| **Ctrl / Cmd + ; (Semicolon)** | Show / hide guides |
| **Ctrl / Cmd + ' (Apostrophe)** | Show / hide the alignment grid |

### Work Area
| Shortcut | Action |
|----------|--------|
| **Ctrl / Cmd + Alt / Opt + B** | Set the work area to the exact duration of the selected layers |

---

**Quick tips:**
- **Shift + number** jumps to a *composition marker* (markers added with **Numpad \*** or the Marker menu) — so **Shift + 2** snaps to the second marker. Great for hitting beat-synced or section markers instantly.
- **Ctrl/Cmd + R** toggles rulers in the Comp panel; drag from a ruler to create a guide, then hide it with **Ctrl/Cmd + ;** without deleting it. The **Apostrophe** grid is your alignment helper for layout work.
- **Ctrl/Cmd + Alt/Opt + B** trims the work area to exactly bracket your selected layers — the fastest way to set a RAM-preview / render range to just the layers you care about. Pairs perfectly with **B / N** and **Numpad 0**.
