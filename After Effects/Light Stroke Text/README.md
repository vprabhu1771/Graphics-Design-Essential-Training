#  Light Stroke Text Tutorial in After Effects | Text Reveal | Text Animation 
```
https://www.youtube.com/watch?v=hfCAdQQJrqw
```

```
Light Stroke Text

CTRL -> N -> New Composition

Create Text Layer -> some text

Text Layer -> Right Click -> Create -> Create Masks from text 

Select Text Layer -> Effects -> Generate -> Stroke

# Stroke Settings
Paint Style -> On Transparent
End -> Add Key -> 0 to 100



CTRL + Y -> New Solid Layer

Select Solid Layer -> Effects -> Generate -> Element -> Lens Flare

Select Text Outlines -> Press M for mask path -> Copy Mask Path

Select Solid Layer -> Lens Flare -> Flare Center -> Paste Mask Path
```
