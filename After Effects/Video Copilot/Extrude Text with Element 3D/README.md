#  Extrude Text with Element 3D 
```
https://www.youtube.com/watch?v=x0p9gwKMSqk
```

CTRL -> N -> New Composition

CTRL + Y -> New Solid Layer

Create Text Layer -> some text

Select Solid Layer -> Effects -> Video Copilot -> Element -> Custom Layers -> Custom Text and Masks -> Path Layer 1 

Select Text Layer

Open Scene Setup -> Extrude  -> OK
